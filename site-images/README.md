# Joes Technologies image carousel

This folder contains 20 numbered SVG placeholder images used by the project showcase carousel.

Replace `image-1.svg` through `image-20.svg` with your own image files, keeping the filenames and `.svg` extension if you use SVG. If you prefer JPG or PNG images, update the image filenames in the carousel script in `index.html` to match. The carousel checks all 20 files and changes images every 5 seconds. Both project panels rotate independently through the available files.

The placeholder images are designed to keep the carousel populated until you replace them. You can upload your real project screenshots or photos directly into this folder.
