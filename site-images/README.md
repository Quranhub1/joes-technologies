# Joes Technologies site images

Place your portfolio images in this folder using these filenames:

- `image-1.jpg`
- `image-2.jpg`
- `image-3.jpg`
- ... up to `image-12.jpg`

The project image panels on the homepage automatically find available images in this list and rotate to the next available image every 5 seconds. Missing filenames are skipped. Use JPG images for this naming convention. Keep image files reasonably compressed for faster page loading.
